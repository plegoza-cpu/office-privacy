# Office – Adatvédelmi tájékoztató / Privacy Policy

Az "Office" alkalmazás kizárólag a tulajdonos saját Google-fiókjához fér hozzá (Gmail, Naptár, Drive, Névjegyek), saját belső irodai asszisztensi célra.

- Az adatokat harmadik félnek nem adjuk át, nem értékesítjük, és reklámcélra nem használjuk.
- Az adatok csak a tulajdonos saját szerverén kerülnek feldolgozásra.
- A hozzáférés bármikor visszavonható: myaccount.google.com → Biztonság → Harmadik féltől származó alkalmazások.

---

The "Office" application accesses only its owner's own Google account (Gmail, Calendar, Drive, Contacts) for the owner's private back-office assistant use.

- Data is never shared with third parties, sold, or used for advertising.
- Data is processed only on the owner's own server.
- Access can be revoked at any time at myaccount.google.com → Security → Third-party apps.

Google API usage complies with the Google API Services User Data Policy, including the Limited Use requirements.
